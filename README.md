# TradeBridge

Telegram bot for retail traders to manage broker/exchange accounts via user API keys; supports per-account live/paper modes, explicit confirmations, and DM + email notifications.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
